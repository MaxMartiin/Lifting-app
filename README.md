# Lifting Tracker

A full-stack progressive overload tracking app for personal training.

**Live app:** https://lifting-app-rho.vercel.app

## Stack
- Backend: Python / FastAPI / SQLite
- Frontend: React / Tailwind CSS
- Deployed: Railway (backend) + Vercel (frontend)

## Features
- Log sets with weight and reps
- Adaptive weight recommendations based on double-progression
- Session persistence — picks up where you left off
- Mobile-first design, works at the gym
